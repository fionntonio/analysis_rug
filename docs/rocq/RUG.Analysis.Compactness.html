Sequential compactness and open covers

Sequential compactness: every sequence in K has a subsequence converging to a point of K. Here phi is a strictly increasing index map. This is the "Bolzano–Weierstrass" notion of compactness used in the lecture.
Definition sequentially_compact (K : ℝ → Prop) : Prop :=
  ∀ a : ℕ → ℝ, (∀ n : ℕ, a n ∈ K) →
    ∃ phi : ℕ → ℕ, ∃ x : ℝ,
      (∀ n : ℕ, (phi n < phi (S n))%nat) ∧ K x ∧
      (fun k ⇒ a (phi k)) ⟶ x.

An open cover of K is a family (U i) of open sets whose union contains K.
Definition open_cover {I : Type} (U : I → (ℝ → Prop)) (K : ℝ → Prop) : Prop :=
  (∀ i : I, (U i) is _open_) ∧ (∀ x : ℝ, K x → ∃ i : I, U i x).

K admits a finite subcover from (U i) if finitely many indices i₁, …, iₙ already cover K.
Definition has_finite_subcover {I : Type} (U : I → (ℝ → Prop)) (K : ℝ → Prop)
    : Prop :=
  ∃ l : list I, ∀ x : ℝ, K x → ∃ i : I, In i l ∧ U i x.

Closed intervals are compact

Every closed bounded interval is compact (Heine-Borel, one direction).
Proof idea: given a sequence in [a,b], Bolzano–Weierstrass provides a convergent subsequence, and the order limit theorem places its limit in [a,b] (from a ≤ xₙ ≤ b).
Theorem segment_compact (a b : ℝ) :
    [a, b] is _compact_.
Proof.
  By closed_interval_is_compact we conclude that [a, b] is _compact_.
Qed.

Compact sets are closed and bounded

Every sequentially compact set is closed.
Proof idea: if x is a limit point of K, take a sequence in K converging to x. By compactness it has a subsequence converging to some y ∈ K; but subsequences of a convergent sequence share its limit, so x = y ∈ K.

Heine-Borel theorem

Heine–Borel theorem: a subset of ℝ is sequentially compact iff it is closed and bounded.
Proof idea: (⇒) is the two lemmas above. (⇐) given a sequence in a bounded K, Bolzano–Weierstrass gives a convergent subsequence, and closedness places its limit in K.
Theorem sequential_Heine_Borel (K : ℝ → Prop) :
    sequentially_compact(K) ⇔ (K is _closed_ ∧ K is _bounded_).
Proof.
  We show both directions.

  - We need to show that
      sequentially_compact(K) → (K is _closed_ ∧ K is _bounded_).
    Assume that sequentially_compact(K) as (HK).

    By (sequentially_compact_implies_closed K HK) it holds that
      K is _closed_ as (Hclosed).
    By (sequentially_compact_implies_bounded K HK) it holds that
      K is _bounded_ as (Hbounded).
    We conclude that K is _closed_ ∧ K is _bounded_.

      (K is _closed_ ∧ K is _bounded_) → sequentially_compact(K).

Closed subsets of compact sets are compact

A closed subset of a compact set is compact.

Bounded infinite sets have a limit point

If (aₙ) is a bounded injective sequence in A, then A has a limit point.
Proof: Bolzano-Weierstrass gives a convergent subsequence a_{φ(k)} → x. Then x is a limit point of A: every ball around x contains infinitely many terms a_{φ(k)}, all distinct from each other, and all in A.
Theorem inj_bounded_seq_has_limit_point
    (A : subset ℝ) (a : ℕ → ℝ) :
  inj_seq_in A a →
  
  has_ub a →
  has_lb a →
  ∃ x ∈ ℝ, x is a _limit point_ of A.
Proof.
  Assume that (∀ n : ℕ, a n ∈ A) ∧ (∀ n m : ℕ, (n ≠ m)%nat → a n ≠ a m).
  It holds that ∀ n : ℕ, a n ∈ A as (Ha_A).
  It holds that ∀ n m : ℕ, (n ≠ m)%nat → a n ≠ a m as (Ha_inj).
  Assume that has_ub a.
  Assume that has_lb a.

  By Bolzano_Weierstrass it holds that
    ∃ (phi : ℕ → ℕ), ∃ (x : ℝ), is_index_seq phi ∧
      converges_to (fun k ↦ a (phi k)) x as (HBW).

  Obtain phi according to (HBW).
  It holds that ∃ (x0 : ℝ), is_index_seq phi ∧ converges_to (fun k ↦ a (phi k)) x0.
  Obtain such a x0.

  It holds that is_index_seq phi as (Hphi_is).
  It holds that (fun k ↦ a (phi k)) ⟶ x0 as (Hphi_cv).

  Choose x := x0. { Indeed, x ∈ ℝ. }

  
  We need to show that ∀ ε > 0, ∃ y ∈ A, 0 < | y - x | < ε.
  Take ε > 0.

  By (Hphi_cv) it holds that
    ∃ M ∈ ℕ, ∀ n ≥ M, | a (phi n) - x | < ε / 2 as (Hphi_cv').
  Obtain M according to (Hphi_cv').

  Either (a (phi M) = x) or (a (phi M) ≠ x).
  - Case (a (phi M) = x).
    Choose y := a (phi (S M)). {
      We need to verify that y ∈ A.
      By (Ha_A) it holds that a (phi (S M)) ∈ A.
      We conclude that y ∈ A.
    }
    We need to show that 0 < | y - x | < ε.

    By (Hphi_cv') it holds that (&
      | y - x |
      = | a (phi (S M)) - x |
      < ε / 2 < ε
    ).

    By (Hphi_is) it holds that phi M < phi (S M).
    By Nat.lt_neq it holds that phi M ≠ phi (S M).
    By (Ha_inj) it holds that a (phi M) ≠ a (phi (S M)).
    By neq_implies_abs_pos it holds that 0 < | y - x |.

    We conclude that 0 < | y - x | < ε.

  - Case (a (phi M) ≠ x).
    Choose y := a (phi M). {
      We need to verify that y ∈ A.
      By (Ha_A) it holds that a (phi M) ∈ A.
      We conclude that y ∈ A.
    }
    We need to show that 0 < | y - x | < ε.

    By (Hphi_cv') it holds that (&
      | y - x |
      = | a (phi M) - x |
      < ε / 2 < ε
    ).

    By neq_implies_abs_pos it holds that 0 < | y - x |.

    We conclude that 0 < | y - x | < ε.
